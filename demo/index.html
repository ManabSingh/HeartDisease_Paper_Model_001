Model Architecture

Stacking Ensemble Architecture — Three base learners feeding into a Logistic Regression meta-classifier
🧬

XGBoost (Base Learner 1)

Gradient boosted trees with Optuna-tuned hyperparameters. Excels at capturing non-linear feature interactions.

⚡

LightGBM (Base Learner 2)

Histogram-based gradient boosting with leaf-wise growth. Provides fast, efficient tree ensembles.

🌲

Random Forest (Base Learner 3)

Bagged ensemble of decision trees. Offers diversity through bootstrap sampling and feature randomization.

🧑‍⚕️

Logistic Regression (Meta-Learner)

The "Chief of Medicine" — takes the 3 base predictions and learns optimal weights using 5-fold cross-validation (C=0.1).

Research Finding #1 — Generalizability Degradation

When the model — trained on Cleveland — was deployed to the unseen Statlog population, accuracy dropped from 100% to 81.48%, and recall fell to 74.2%. This demonstrates that ML models suffer from poor generalizability when exposed to data from different patient cohorts.

Research Finding #2 — Feature Importance Shift

The diagnostic logic of the model changes across datasets. Features that dominate predictions on Cleveland may rank differently on Statlog. This proves that ML diagnostic reasoning is unstable and data-dependent — a critical concern for clinical deployment.

Methodology Pipeline

1

Data Acquisition

Cleveland (303 patients) as source domain. Statlog (270 patients) as unseen target domain. Feature harmonization for cross-domain compatibility.

2

Preprocessing

Missing value imputation, outlier removal (IQR), one-hot encoding for categoricals, standard scaling, and SMOTE-ENN class balancing.

3

Hyperparameter Tuning

Optuna-based Bayesian optimization for XGBoost, LightGBM, and Random Forest. Each tuned independently with cross-validation.

4

Stacking Ensemble

Three tuned base learners feed 5-fold out-of-fold predictions into a regularized Logistic Regression meta-learner (C=0.1).

5

Cross-Domain Deployment

The Cleveland-trained ensemble is deployed to the unseen Statlog dataset to evaluate real-world generalizability and accuracy degradation.

6

SHAP & Shift Analysis

Feature importance extracted via SHAP on both domains. Attribution shift analysis reveals how model reasoning changes across populations.
